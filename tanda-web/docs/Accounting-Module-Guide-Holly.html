Accounting module user guide

How to configure rates and rules, run a clean test week, and use every export — including Xero Location tracking by state.

Audience: Accounting / finance administrators
Module path: Finance → Accounting
Prepared for: Holly · Continental Cargo
Version: March 2026

1. What this module does

Accounting turns real clocked hours into pay (wage cost) and charge (client billing), then produces the files you need for invoicing, Xero, and internal analysis.

Pay

What labour costs — based on staff hourly rates and pay matrices.

Charge

What you bill clients — based on client/site rate cards.

Margin

Charge − Pay for the selected week or filters.

Exports

Xero sales & bills, client timesheets, journals, charge packs.

Important Admin / master / kiosk accounts are not workforce staff. Always use a real employee record for timesheets and rate cards.

2. Configure this first (recommended order)

Do these steps before expecting non-zero dollars or working exports.

  1. Confirm your access role
    Your role needs the Accounting module plus: Edit staff and site rate cards, Edit pay rules, bands, and holidays, and Export accounting reports (CSV). Without Export you will see “No export permission”.
  2. Set client states (for Xero Location tracking)
    Go to Settings → Clients. For each client/site, set State to NSW, QLD, VIC, etc. This matches your Xero tracking category Location.
  3. Company rules
    Accounting → Setup → Pay and charge rules
    Review week start, rounding, minimum hours, time bands, day types, overtime, public holidays, employment types / GL codes, and Xero settings.
  4. Company default matrices
    Accounting → Setup → Rate cards → Company defaults
    Adjust default pay % and charge % (or switch cells to fixed $).
  5. Staff rates
    Accounting → Setup → Rate cards → Staff
    Select a real employee and set a base hourly rate greater than $0. Most default cells are percentages of this rate.
  6. Client charge cards
    Accounting → Setup → Rate cards → Clients
    Set charge matrix and optional Client time bands (e.g. early morning 02:00–05:00). Leave bands empty to inherit company bands.

3. Key concepts (quick reference)

TermMeaning
Client / site Same record as Settings → Clients (warehouse / customer site).
Time band Part of the day (e.g. Early morning 00:00–06:00). A shift is split across bands.
Day type Weekday, Saturday, Sunday, or Public holiday.
Rate matrix Day type × time band grid. Each cell is $ or %.
Hourly rate Staff base $/hour. If cells are %, $0 hourly → $0 everywhere.
Weekly close Freezes the week’s figures so late punches don’t change locked totals.

4. How to run a test (end-to-end)

Goal of the test Prove that hours → non-zero pay/charge → exports (including Xero Location).
  1. Finish Section 2 setup for at least one employee and one client (with State set).
  2. Create attendance for that employee (kiosk, employee app, or Attendance → Add manual record). Do not clock the accounting admin user.
  3. Open Accounting → Overview. Confirm Pay / Charge are not $0 for the week. If they are, check hourly rate and matrices.
  4. Open Accounting → Weekly close, select the week, review exceptions, then click Close week.
  5. Open Accounting → Exports and download: Xero sales invoices, Xero bills, Client timesheet, Charge pack.
  6. In the Xero sales CSV, confirm columns TrackingName1 / TrackingOption1 (e.g. Location / NSW) when Location tracking is enabled.
If everything is $0 Almost always: staff hourly rate is still 0 while matrices are %, or hours were logged on an admin account. Fix the rate card, then re-check Overview.

5. Using each area of the module

5.1 Overview

Health dashboard for the latest week: Open/Closed status, totals, setup warnings, and shortcuts into Setup, Weekly close, and Exports.

5.2 Setup → Pay and charge rules

SectionWhat you configure
Week rules Week start day and hours rounding.
Minimums & leave Minimum pay/charge hours; optional paid approved leave.
Time bands Company-wide bands (default Early morning / Afternoon). Change to 02:00–05:00 if needed.
Day types Rows of the matrix (weekday / Sat / Sun / public holiday).
Overtime Daily and weekly thresholds (0 = off).
Public holidays Dates; optionally limited to specific clients.
Allowances Fixed add-ons per hour or session (pay, charge, or both).
Employment types & GL FT/PT/Casual/Contractor labels and expense/payable account codes.
Xero export settings Sales/bill account codes, tax types, prefixes, description templates, due days, Location tracking.

5.3 Setup → Rate cards

Staff

  • Employment type
  • Base hourly rate ($) — required for % matrices
  • Optional min pay hours / effective from
  • Pay matrix overrides (or inherit company defaults)

Clients

  • Charge matrix for that site
  • Client time bands — empty = inherit company; otherwise per-client early morning windows
  • Optional min charge hours

Company defaults

Fallback pay and charge matrices for anyone without a personal/site override.

5.4 Weekly close

  • Pick the pay week
  • Review exceptions (incomplete sessions, min hours, overtime, missing cards)
  • Close week freezes totals
  • Reopen week returns to live calculation (needs rules permission)

5.5 Exports

FileUse it for
Xero sales invoices Import client labour charges into Xero (one line per site/week). Includes Location tracking when enabled.
Xero bills Import wage/contractor expense lines. With Location tracking on, lines split by staff + site so each can carry a state.
Client timesheet CSV Detailed staff/band hours and amounts to send with a client invoice.
Charge pack Internal billing pack by site and band.
Journal Debit/credit style lines by employment type / GL codes.
Summary Aggregated pay/charge/margin for the current analysis filters.

Advanced analysis lets you switch views (Pay, Charge, Margin, Timesheet, Journal, Charge pack) and group by Staff, Client, Day, Band, or Employment type.

6. Xero Location tracking (your request)

Aligned with Xero → Settings → Tracking categories → Location (NSW / QLD / VIC…).

  1. In Tanda: Settings → Clients → set each client’s State.
  2. In Tanda: Accounting → Setup → Pay and charge rules → Xero export settings → Location tracking category
  3. Keep tracking enabled and category name exactly Location (must match Xero).
  4. Export Xero sales / bills — CSVs include TrackingName1 and TrackingOption1.

7. Client time bands (early morning)

Company bands live under Pay and charge rules. Per-client bands live under Rate cards → Clients → Client time bands.

  • Empty client bands → inherit company (default Early morning 00:00–06:00).
  • Set client bands when a warehouse needs 02:00–05:00 or 01:00–08:00 specifically.
  • Overnight wrap is supported (e.g. 22:00–06:00).

9. Checklist before you rely on a week

  • Role has Accounting + rates + rules + export
  • Clients have State set (for Xero Location)
  • Company rules and default matrices reviewed
  • Staff hourly rate > 0
  • Client charge card configured (or happy with company defaults)
  • Hours logged on a real employee
  • Overview shows non-zero totals
  • Week closed (optional but recommended for final exports)
  • Xero CSVs checked for tracking columns
