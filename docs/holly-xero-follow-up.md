**Subject:** Accounting / Xero exports — please set your codes in Setup

Hi Holly,

Thank you again for confirming the rules and for the CSV templates.

The Accounting module now includes a **Setup → Xero export settings** section so you can change every import field yourself (nothing is locked in code). Example values are pre-filled; please replace them with the ones from your Xero organisation before go-live.

**Where to look**

1. **Accounting → Setup → Employment types & GL**  
   Confirm Full Time / Part Time / Casual / Contractor and the expense codes (**Wage**, **Contracting Expense**).

2. **Accounting → Setup → Xero export settings**  
   - Sales account code and tax type (charges)  
   - Bill tax type, contact mode (per staff vs one shared contact), prefixes, description text  
   - Due days after invoice date  

3. **Accounting → Exports**  
   - **Xero sales invoices** — one charge line per site for the week  
   - **Xero bills** — one pay line per staff member for the week  
   - **Client timesheet CSV** — detail for the invoice you send to clients  

**Optional questions** (only if anything is unclear after you try the screen)

1. For the detailed client invoice (time in / out / break / $ per band): is the **CSV** enough for now, or do you still need a formatted **PDF** matching your current invoice layout?

2. If any TaxType or account code does not import into Xero, please reply with the exact names/codes from your Xero chart so we can check the export format.

After you save your settings in Setup, the next export will use them automatically.
